# Apply or reply

- **(a)** Make the smallest fix. Stay in files the original plan (or this
  comment) clearly implies. Run targeted checks if project-checks exists.
- **(b)** Do not code. Flag the scope change and that `@plan` may need a
  revision. Wait.
- **(c)** Draft a reasoned reply. Do not post it or change code until the
  engineer confirms. Do not be snarky.

Do not address a second comment in this run.
