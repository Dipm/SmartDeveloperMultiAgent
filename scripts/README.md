# SmartDeveloper scripts

All scripts use the `smartDevByDipali_` prefix so they do not clash with other tools on your system.

| Script | Purpose |
|--------|---------|
| `smartDevByDipali_installGlobal.py` | Install SmartDeveloper once on your machine (`~/.cursor/`) |
| `smartDevByDipali_installGlobal.sh` | Shell wrapper for global install |
| `smartDevByDipali_onboardProject.py` | Add two config files to one app project |
| `smartDevByDipali_onboardProject.sh` | Shell wrapper for project onboarding |
| `smartDevByDipali_mergeHooks.py` | Build merged `hooks.json` (used during install) |
| `smartDevByDipali_validatePipeline.py` | Validate package layout |
| `smartDevByDipali_runTests.py` | Run hook tests |
| `smartDevByDipali_bootstrapProject.py` | Legacy: copy full tree into a project |
| `smartDevByDipali_names.py` | Shared script name constants |

Hook wrapper: `hooks/smartDevByDipali_hookWrapper.py`

See [SmartDeveloper-User-Guide.pdf](../SmartDeveloper-User-Guide.pdf) for step-by-step usage.

| `smartDevByDipali_buildUserGuidePdf.py` | Build `SmartDeveloper-User-Guide.pdf` from source |
